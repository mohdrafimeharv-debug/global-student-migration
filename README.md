Global Student Migration Analysis

Project Overview

This project analyses student migration patterns, study destinations, scholarships, enrollment reasons, and employment outcomes using Python.

Objectives

- Identify the top 10 student destination countries.
- Analyze the reasons students choose the UAE.
- Identify the top 10 origin countries.
- Explore scholarship distribution by origin country.
- Compare placement status with academic scores (CGPA).
- Compare average starting salaries by placement country and field of study.
- Explore relationships between origin and destination countries.

Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Data Cleaning

- Handled missing values where appropriate.
